# Server Sentinel Platform

Hệ thống Tự động hóa Giám sát, Bảo trì & Sao lưu Server Linux.

## Các tính năng chính:
- **Phase 1:** Local Telemetry Script (Thu thập RAM/CPU/Disk).
- **Phase 2:** Systemd Service & Timer (Tự động hóa chạy định kỳ).
- **Phase 3:** Remote Backup via SSH/Rsync (Bảo mật & Sao lưu Server B).
- **Phase 4:** Enterprise Refactoring (Set -euo pipefail, Idempotent, Env Separation).
